# PromptVault — automated prompt-pack site

A fully scripted pipeline: `content/packs.json` → PDF prompt packs → landing pages → deployable static site.
No manual design work — everything is generated by `scripts/generate.py`.

## What's here

- `content/packs.json` — the actual content (5 prompt packs to start). Add more packs by adding entries here.
- `scripts/generate.py` — regenerates the entire `site/` folder: PDFs + landing pages + homepage.
- `scripts/templates/` — the HTML/CSS templates used to render PDFs and pages (edit these to change the design once, and every pack updates).
- `scripts/deploy.sh` — pushes `site/` to Vercel with one command, no git required.
- `site/` — the generated output. This is what gets deployed.

## One-time setup (only you can do these — identity/account steps)

1. **Vercel token**: create one at vercel.com/account/tokens, then run:
   `VERCEL_TOKEN=your_token ./scripts/deploy.sh`
2. **ShrinkEarn API key**: from your ShrinkEarn account → API settings. Export it before generating:
   `SHRINKEARN_API_KEY=your_key python3 scripts/generate.py`
   Without it, download buttons link directly to the PDF (still works, just not monetized).
3. **SITE_URL**: once you have your real Vercel URL (or custom domain), set it so PDFs/links point to the right place:
   `SITE_URL=https://your-real-domain.vercel.app SHRINKEARN_API_KEY=xxx python3 scripts/generate.py`

## Recurring pipeline (fully automated once set up)

Once the two keys above are wired in as environment variables, the whole cycle —
add new pack content → generate PDFs → create ShrinkEarn links → build pages → deploy —
can run unattended on a schedule with no manual steps.

## Adding a new prompt pack

Add a new object to the `packs` array in `content/packs.json` (slug, title, category, tool,
description, prompts[]) and re-run `generate.py`. That's the only "content" step — everything
else (PDF, page, link, deploy) is automatic.
